# 🐾 동물 할리갈리 — 12간지 대전

휴대폰 세로 화면용 첫 대전 테스트 버전입니다. 최종 이미지는 교체 예정인 임시 이모지를 사용합니다.

## 실행

GitHub의 Code → Codespaces → Create codespace on main으로 열면 설치 후 개발 서버가 시작됩니다. Ports의 5173을 브라우저로 열어 플레이합니다.

```sh
npm install
npm test
npm run dev
```

SDK 설치 없이 바로 실행하려면 Python 3으로 `python3 -m http.server 5173 --bind 0.0.0.0`을 실행해도 됩니다. 게임 자체는 외부 라이브러리가 없는 HTML/JS입니다.

## 난이도

| 단계 | 동물 종류 | 컴퓨터 반응 | 참가비 | 승리 보상 |
|---|---:|---|---:|---:|
| 초보 | 3 | 1.8–2.5초 | 10 | 15 |
| 중수 | 6 | 0.9–1.4초 | 15 | 25 |
| 고수 | 9 | 0.35–0.65초 | 20 | 35 |
| 초고수 | 12 | 0.2–0.35초 | 30 | 50 |

중수 이상 금액과 하루 무료 50코인은 임시값입니다. 승리 보상은 참가비를 차감한 뒤 지급하는 총액입니다. 동물은 12간지에서 대전마다 무작위로 선택합니다. 종류마다 1·2·3·4·5마리 카드를 각각 1장씩, 총 5장 넣습니다. 초보/중수/고수/초고수의 전체 카드는 15/30/45/60장입니다. 섞은 뒤 번갈아 나눠 주며, 홀수인 경우 내 카드가 1장 더 많습니다. 획득한 카드는 다시 덱 아래로 들어가므로 같은 카드가 이후 다시 나올 수 있습니다.

## 규칙

내 패와 컴퓨터 패의 맨 위 카드만 합산합니다. 같은 동물 정확히 5마리면 누구나 종을 누릅니다. 정답이면 양쪽 공개 카드를 자기 덱 아래에 넣고 먼저 뒤집습니다. 오답이면 상대에게 덱의 카드 1장을 줍니다. 덱이 비어도 다음 자기 차례까지 종을 누를 수 있으며, 자기 차례에 뒤집을 카드가 없으면 패배합니다. 컴퓨터 카드 넘김은 모든 단계에서 0.7초로 같습니다. 종을 누를 수 있는 합계 5마리 상태에서는 다음 카드를 넘기지 않고 종 판정을 기다립니다.

앱 전환과 화면 숨김 시 자동 일시정지하고 재개 시 타이머를 새로 예약합니다. 먼저 누른 종이나 카드 변경 후 이전 컴퓨터 입력은 취소됩니다. 새로고침과 포기는 참가비를 반환하지 않습니다.

## 코인 및 광고

코인은 localStorage에 보관하는 테스트 구현입니다. 기기 변경·브라우저 데이터 삭제 시 유지되지 않으며 조작 방지 기능이 없습니다. 출시 전에 사용자별 서버 지갑과 일일 지급·참가비·승리 보상의 검증 및 중복 방지 처리가 필요합니다. 광고 버튼은 준비 중 안내만 표시하고 보상을 지급하지 않습니다. 실제 토스 광고 SDK와 완료 이벤트 검증은 미구현입니다. 일일 광고 횟수 제한을 자체적으로 두지 않는 요구사항은 광고 공급 및 SDK 정책 범위에서 추후 적용합니다.
