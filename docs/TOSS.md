# 앱인토스 배포 준비

배포 대상은 토스 앱 내부에서 실행되는 WebView 미니앱입니다. 현재 게임은 연습용 초안이고, 이 문서는 SDK 배포 구성을 설명합니다. 실제 출시나 심사 완료를 의미하지 않습니다.

## 개발 및 빌드

Node.js 22 이상을 사용합니다.

```sh
npm install
npm test
npm run dev
```

Codespaces에서 5173 포트를 브라우저로 열어 화면을 확인합니다.

```sh
npm run build:web
npm run build
```

`build:web`은 웹 파일을 `dist/`에 생성합니다. `build`는 웹 빌드 후 공식 SDK의 `ait build`로 앱인토스 번들을 생성합니다. SDK 설치 및 패키징 성공 여부와 토스 앱 실기기 동작은 별도로 검증해야 합니다. 의존성 설치가 성공하면 생성된 `package-lock.json`도 저장소에 커밋합니다.

## 출시 전에 필요한 작업

1. 앱인토스 콘솔에서 앱을 등록합니다. `apps-in-toss.config.ts`의 `appName: 'animal'`은 임시 값입니다. 콘솔에 등록한 정확한 appName으로 맞춥니다.
2. 콘솔에서 게임 정보, 실제 사용할 이름과 아이콘 등 필수 정보를 등록합니다.
3. 게임의 정식 규칙, 컴퓨터 대전, 난이도와 시안 기반 이미지를 구현합니다. 현재 연습용 게임 그대로 출시하지 않습니다.
4. `npm run build`로 생성한 번들을 콘솔에 업로드하고 토스 앱 QR 테스트를 진행합니다.
5. 실기기에서 화면 안전 영역, 뒤로가기, 앱 전환 시 일시정지, 재시작, 터치 반응 및 종 판정 타이머를 검증합니다.
6. 콘솔의 게임 심사 항목을 완료한 뒤 검토를 요청합니다. 실제 공개는 검토 및 콘솔 출시 절차를 거칩니다.

로그인, 광고, 결제, 리워드는 현재 추가하지 않습니다. 필요할 때 각각의 공식 SDK와 권한을 연결합니다. 배포 키와 인증 정보는 GitHub 소스에 저장하지 않습니다.

## 확정된 게임 요구사항

- 시안의 8종 동물, 숲과 나무 테이블, 파스텔 카드, 빨간 발바닥 종
- 위쪽 컴퓨터 공개 패와 아래쪽 내 공개 패를 함께 표시
- 내 차례의 카드 넘기기 버튼 및 언제든 누를 수 있는 종 버튼
- 컴퓨터 차례에 자동 카드 넘김
- 공개 패 맨 위 카드만 합산해 같은 동물이 정확히 5마리일 때 종 판정
- 공개 카드 획득, 잘못된 종의 카드 지급, 카드 소진 및 탈락 처리를 포함한 기본 규칙
- 초보 1.8–2.5초, 중수 0.9–1.4초, 고수 0.35–0.65초의 컴퓨터 종 반응 시간
- 정답 상태가 바뀌거나 플레이어가 먼저 종을 누르면 예약된 컴퓨터 종 입력 취소
