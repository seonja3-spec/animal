# 동물의 종 이미지

사용자가 제공한 `animal.zip`의 PNG 원본을 웹용 WebP로 변환했습니다.
투명 배경과 원본 그림을 유지하며 배경은 최대 960×1600, 프레임은 512×720,
동물과 종은 320×320 범위로 축소했습니다.

파일명 연결: mouse=쥐, cow=소, tiger=호랑이, rat=토끼, yong=용,
snake=뱀, hors=말, yang=양, mong=원숭이, ggo=닭, dog=개, pig=돼지.
back=숲 배경, frame=카드 테두리, bell1=기본 종, bell2=누른 종.

동물 판정과 카드 수는 이미지 파일명과 별개인 기존 rules.js ID를 사용합니다.
